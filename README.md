# 🚀 Camsur Level-Up Portal (Laravel 13)

A modernized web application for the Camarines Sur web platform, upgraded from **Laravel 5.2 (Bootstrap 4.6)** to **Laravel 13** using **Tailwind CSS**.

---

## 📌 Features

- 🔐 **Authentication Scaffolding:** Built-in Login, Registration, and Password Management via Laravel Breeze.
- 🎨 **Modern Tech Stack:** Powered by Laravel 13, Tailwind CSS, Alpine.js, and Vite.
- 📁 **Organized View Architecture:** Separated route views for guest users (`pages/guest/`) and authenticated users (`pages/authenticated/`).
- 🧩 **Preloaded Reusable Components:**
  - Dynamic Alert Notifications (`<x-alert />`)
  - Container Cards (`<x-card />`)
  - Dashboard Metric/Stat Boxes (`<x-stat-box />`)
  - Interactive Loading Screen (`<x-loading-screen />`)
